# CGJteam Lab

CGJteamLab is an open research project dedicated to the formal verification of synthetic Euclidean geometry in Lean 4.

The project develops a reusable library for synthetic geometry while documenting the formalization process through technical logs, mathematical notes, and case studies.

The first case study is Ian Finlay's synthetic proof of the concurrency of the three medians of a triangle. The proof is investigated through different axiomatic frameworks, providing a concrete test case for the structure, dependencies, and reducibility of formal geometric arguments.

## Current Status

Active research project.

The library is under continuous development. Temporary axioms introduced during formalization are systematically investigated and, where possible, replaced by formally verified theorems.

The current work includes the reconstruction and comparison of proofs based on Hilbert-style, Tarski-style, and Suppes-style foundations.
